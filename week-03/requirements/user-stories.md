# User stories — Smart Campus

### US-01
**Story:** As a Student, I want to view room availability by time, so that I can choose a free room.
**Priority:** High
**Assumption:** Availability reflects existing reservations and blocked rooms.

### US-02
**Story:** As a Student, I want to book an available room for a time slot, so that I can study there.
**Priority:** High
**Assumption:** A booking has a room, start time and end time.

### US-03
**Story:** As a Student, I want to cancel my booking, so that the room becomes available again.
**Priority:** High
**Assumption:** Only the student who made a booking can cancel it.

### US-04
**Story:** As an Administrator, I want to block or unblock a room, so that unusable rooms cannot be reserved.
**Priority:** High
**Assumption:** Blocking applies to new booking attempts while the room is blocked.

### US-05
**Story:** As an Administrator, I want to review room usage over a period, so that I can understand demand.
**Priority:** Medium
**Assumption:** Usage is based on reservations during the selected period.

### US-06
**Story:** As a Student, I want to receive confirmation of a successful booking, so that I know my reservation was recorded.
**Priority:** Medium
**Assumption:** Confirmation occurs only after a successful booking.

### US-07
**Story:** As a Student, I want to receive confirmation of a successful cancellation, so that I know the reservation was released.
**Priority:** Medium
**Assumption:** Confirmation occurs only after a successful cancellation.
